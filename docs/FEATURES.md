# ShareX Capture Workflow — feature reference

Capture presets, destination fields, and naming rules form the core of ShareX Capture Workflow. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Capture presets | Related settings collected into named groups for a clearer configuration workflow. |
| Destination fields | A dedicated section for destination fields and the configuration details associated with that area. |
| Naming rules | A dedicated section for naming rules and the configuration details associated with that area. |

The project page follows the same section structure.
